# Titillium Web

Source: https://github.com/google/fonts/tree/main/ofl/titilliumweb (downloaded 2026-09-08).
License: SIL Open Font License 1.1, included in OFL.txt.

Regular (400), semibold (600), bold (700), and regular italic (400) WOFF2 files are losslessly compressed from the upstream TTFs with fontTools, retaining the full glyph set. Browsers load only these four local WOFF2 files through next/font/local.

The three upright TTF files support the share-card renderer. No system font installation or external font request is required.
