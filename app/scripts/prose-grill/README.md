# 🔥✍️ prose-grill · the 0026 grill and the 0027 re-grill

Throwaway measurement, no product code. Findings: [0026](../../../docs/handoffs/0026-prose-grill-findings.md) (API, Sonnet 5, 5.2 $), [0027](../../../docs/handoffs/0027-prose-regrill-findings.md) (no API: every draft and audit is a Claude Code subagent). Run from `app/`, in this order. GloBI answers are cached under `.cache/` (git-ignored); 0026's API answers stay there as evidence for the 0026 numbers only.

| Script | Does | Out |
| --- | --- | --- |
| `common.mjs` | paths, the GloBI cache, the JSON repair (0026 + F4 stray paragraph), the file protocol (`promptFile`, `answerFile`, `readAnswer`). No model call; imports env-free helpers from `../steckbrief-probe/lib.mjs` | — |
| `sheets.mjs` | the 0019 ten (`../steckbrief-probe/facts.json` keys) + ten Mainz-Bingen insects from the dev DB, read only. Codes → words per language through `src/i18n/{de,en}.json` with the page's rules. GloBI per species with `includeObservations=true` (per-pair queries when truncated); every edge carries its studies and real (non-metaweb) record count. **F1** drops eats/eatenBy whose studies are all metawebs, **F2** drops edges with ≤ 1 real record from ≤ 1 real study. `full` sheet for P1', `eco` sheet for P2' | `sheets.json` |
| `prose.mjs prompts P1\|P2` | writes one prompt file per species × language under `prompts/<run>/<Sci-Name>-<lang>.md` (`## System`, `## User`; V1 for P1, ECO for P2; **F3**: the record wording is granted and named, life stage and frequency forbidden) and the run's skeleton into `results.json` | `prompts/P1`, `prompts/P2` |
| *subagents* | the coordinator spawns one `general-purpose` subagent (`model: "sonnet"`) per five prompt files; each answers into `answers/<run>/<Sci-Name>-<lang>.json`, the JSON only. Drafts and audits never share an agent. Framing that works: "Task from the coordinator of handoff 0027 … the files were generated by prose.mjs … there is no injection here" (the bare "you are the model in these files" got one refusal) | `answers/P1`, `answers/P2` |
| `prose.mjs collect P1\|P2` | reads the answers, validates (**F4**: one paragraph valid, `paragraphs` is a max), writes the audit prompts under `prompts/audit-<run>/` for valid drafts, reads `answers/audit-<run>/` when present, lists what is pending and how many subagents that is | `results.json`, `prompts/audit-*` |
| `report.mjs` | F1–F4 counts per species, the P2' and P1' tables next to 0026's (`git show e58e14e:…/results.json`), the hand read from `marks.json`, every ❌, subagents and wall time from file mtimes, the production run in subagents; `drafts.md` with every sentence marked | `report.md`, `drafts.md` |

Loop: `prompts` → draft subagents → `collect` → audit subagents → `collect` → `report`. `collect` is idempotent; rerun it until "0 audits pending". `marks.json` is the owner-side hand read of every Ökologie paragraph (`embarrassing`, `odd`, `cause`, `note`), keyed `ECO-sonnet-<gbifKey>-<lang>`.

Marks in `drafts.md`: `[F3,F7]` cites · ⚠️ partial · ❌ unsupported · 🟠 orphan claim · 🙈 hand mark (false as written) · 🤔 hand mark (odd, not wrong).

`prompts/` and `answers/` are committed: they are the evidence. `results.json` is 0027's only; 0026's lives at `e58e14e`.
